# TPMS PRO S3 — مراقب ضغط الإطارات (الإصدار 3.0)

جهاز يلتقط إشارات حساسات ضغط الإطارات على تردد 433.92MHz باستخدام ESP32-S3 وCC1101، ويعرضها على شاشة ST7789 وعلى صفحة ويب من الهاتف.

## العتاد

| القطعة | المنافذ |
|---|---|
| CC1101 (FSPI) | CS=10, MOSI=11, SCK=12, MISO=13, GDO0=4, GDO2=5 |
| شاشة ST7789 320×240 (HSPI) | SCLK=18, MOSI=17, RST=16, DC=21, CS=14, BLK=15 |
| زر | GPIO 1 إلى GND (مقاومة سحب داخلية) |

اللوحة: ESP32-S3 N16R8 (فلاش 16MB، PSRAM 8MB من نوع OPI).

## الاستخدام

**الزر:**
- ضغطة قصيرة: التبديل بين الأوضاع الأربعة: السيارة ← الماسح ← تشخيص الراديو ← فني الإطارات.
- ضغطة مطولة (1.5 ثانية): تشغيل الواي فاي أو إيقافه.

**الأوضاع:**
- **السيارة:** إطاراتك الخمسة فقط (بروتوكولا تويوتا PMV-C210 وPMV-107J). البطاقة تومض بالأحمر عند الخطر.
- **الماسح:** كل الحساسات المحيطة مرتبة من الأحدث إلى الأقدم (25 بروتوكول FSK).
- **تشخيص الراديو:** مقياس RSSI حي لتوجيه الهوائي، مع أرضية الضجيج والعتبة والإحصائيات.
- **فني الإطارات:** لعمال الصيانة. يلتقط الحساس الأقرب فقط، أي الذي تتجاوز إشارته عتبة القرب (افتراضياً -70 dBm)، ويتجاهل السيارات المارّة. يعرض المعرف والبروتوكول والضغط والحرارة والبطارية بخط كبير، مع حكم: سليم، أو بطارية ضعيفة، أو ضغط صفر (غير مركّب؟)، أو حرارة زائدة. يحتفظ بسجل آخر 10 حساسات مفحوصة.

### طريقة عمل فني الإطارات
1. اضغط الزر حتى يظهر `MODE: TIRE TECH`، أو اختر "فني الإطارات" من صفحة الويب.
2. قرّب الجهاز من صمام الإطار، ثم أيقظ الحساس بإحدى هذه الطرق: تنفيس قليل للهواء، أو تدوير العجلة، أو أداة تنشيط TPMS بتردد LF 125kHz.
3. عند الالتقاط يومض إطار الشاشة بالأخضر، وتظهر البيانات والحكم.
4. انتقل إلى الإطار التالي. الحساس الجديد يحل محل السابق، والسابق ينتقل إلى سطر `PREV` وإلى سجل الفحص.
5. عتبة القرب:
   - إن التُقطت سيارات مارّة، فارفع العتبة (+5).
   - إن لم يُلتقط الإطار القريب، فاخفضها (-5).
6. من صفحة الويب يمكن ربط أي حساس مفحوص بإطار من إطارات سيارتك، أو نسخ معرفه.

قاعدة الثبات: إذا كان إطاران متجاورين، يبقى الحساس الملتقط ولا يتبدل إلا إذا جاءت إشارة أقوى بـ 3 dB أو أكثر، أو مرت 10 ثوانٍ.

**صفحة الويب:** اتصل بالشبكة `TPMS-ESP32S3-PRO` (كلمة المرور `12345678`)، وستفتح الصفحة تلقائياً. إن لم تفتح، ادخل إلى `http://192.168.4.1`.

| التبويب | المحتوى |
|---|---|
| إطاراتي | الضغط والحرارة والإشارة وعمر آخر قراءة لكل إطار |
| الماسح | كل الحساسات، مع زر "ربط" لتعيين أي حساس لإطار |
| الإطارات والحدود | المعرفات وحدود الضغط الأدنى والأعلى والحرارة لكل إطار |
| الراديو والهوائي | المقياس الحي، وحساسية الالتقاط، وعرض النطاق، ومعايرة التردد |
| البروتوكولات | تفعيل كل بروتوكول أو تعطيله في وضع الماسح |
| سجل الحزم | آخر 40 حزمة بصيغة JSON |
| النظام | الذاكرة، ومدة التشغيل، وتحديث البرنامج لاسلكياً (OTA)، وإعادة التشغيل |
| فني الإطارات | الحساس الأقرب بخط كبير مع الحكم، وضبط عتبة القرب، و"التقاط جديد"، وسجل الفحص مع زر الربط |

## الإنذارات

| الإنذار | الشرط |
|---|---|
| ضغط منخفض أو مرتفع | خارج الحدود المضبوطة لكل إطار، مع هامش تخلّف (hysteresis) حتى لا يتذبذب الإنذار |
| حرارة مرتفعة | فوق الحد المضبوط |
| **تسريب سريع** | هبوط الضغط 0.2 بار أو أكثر خلال 10 دقائق |
| بطارية ضعيفة | للحساسات التي ترسل حالة البطارية |
| لا إشارة | لم تصل قراءة منذ أكثر من 15 دقيقة (السيارة متوقفة غالباً) |

## نصائح لأبعد مدى مع الهوائي الخارجي

1. افتح وضع **تشخيص الراديو** ووجّه الهوائي حتى تنخفض أرضية الضجيج وترتفع قوة الحزم الملتقطة.
2. **حساسية الالتقاط:** القيمة الافتراضية 9 dB. خفضها إلى 6–7 يلتقط إشارات أضعف، مع ضجيج أكثر.
3. **عرض النطاق:** القيمة الافتراضية 102 kHz هي الأفضل في اختبار ميداني على حركة مرور حقيقية: فكّت إشارات حتى -98 dBm، مقابل -93 dBm عند 270 kHz. القيم الأضيق (68–81 kHz) خسرت حساسات منحرفة التردد.
4. **معايرة التردد:** بلورات CC1101 تنحرف عادة 20–50 kHz. جرّب إزاحات بخطوة 5 kHz، وراقب عدد الحزم المفكوكة.

## البناء والرفع
البناء من جذر المستودع بالمكتبة الموحّدة TPMS_RTL433. التفاصيل الكاملة في [BUILD.md](BUILD.md).

```bash
tools/build.sh r3 COM4
```

### أوامر المنفذ التسلسلي (115200)

| الأمر | الوظيفة |
|---|---|
| `stat` | إحصائيات فورية |
| `mode 0` / `mode 1` / `mode 2` / `mode 3` | تبديل الوضع: سيارة / ماسح / راديو / فني |
| `bw N` / `rssi N` / `foff N` | عرض النطاق / حساسية الالتقاط / إزاحة التردد |
| `techthr N` / `techreset` | عتبة القرب لوضع الفني / التقاط جديد |
| `inject JSON` / `cleartires` | حقن حزمة تجريبية / مسح البيانات (للاختبار) |
| `shot` | تصدير صورة الشاشة (RGB565 بترميز base64) |
| `reboot` | إعادة التشغيل |

كل حزمة مقبولة تُطبع بالشكل `[RF] {...}`، والمرفوضة بفلتر المنطقية بالشكل `[RF-REJ] {...}`.
