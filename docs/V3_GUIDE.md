# دليل النسخة 3 (V3): وحدتان، راديو وشاشة

تتكوّن هذه النسخة من لوحتين منفصلتين تتصلان بكيبل تسلسلي:

| الوحدة | اللوحة | البرنامج | المنفذ عندي |
|---|---|---|---|
| الراديو | ESP32 + CC1101 | `examples/TPMS_V3_Receiver` | COM5 |
| الشاشة | CYD 2.8" صفراء (ESP32-2432S028، ST7789 + لمس XPT2046) | `examples/TPMS_V3_CYD_Display` | COM6 |

## لماذا هذا التقسيم؟
- **وحدة الراديو** لا تقوم إلا بالاستقبال. ليس فيها واي فاي ولا شاشة، فكل وقت المعالج لـ CC1101 والمفككات.
- **وحدة الشاشة** هي العقل. فيها معرّفات الإطارات والحدود والإنذارات والواجهة **والواي فاي**.
  - في القياس، رفع الواي فاي القريب من CC1101 أرضيةَ الضجيج نحو 4 dB.
  - وضعه في لوحة منفصلة يُبقي الاستقبال على حاله تماماً.

## التوصيل

| وحدة الراديو | CYD (منفذ CN1) |
|---|---|
| GPIO17 (TX) | GPIO22 (RX) |
| GPIO16 (RX) | GPIO27 (TX) |
| GND | GND |

### توصيل CC1101 بوحدة الراديو

| CC1101 | ESP32 |

| SCK | 18 |
| MISO | 19 |
| MOSI | 23 |
| CSN | 22 |
| GDO0 | 21 |
| GDO2 | 27 |

## بروتوكول الربط TPMS-LINK v2
- كل رسالة سطر واحد بالشكل `$<json>*<XOR بالست عشري>\n`، والسرعة 115200.
- أي سطر يفشل في المجموع يُرمى.

**من الراديو إلى الشاشة:**

| الرسالة | المحتوى |
|---|---|
| `P` | حزمة: `p` البروتوكول، `id`، `k` الضغط kPa، `c` الحرارة، `b` البطارية، `lk` تسريب، `r` RSSI |
| `S` | الحالة كل ثانية: التردد، عرض النطاق، الضجيج، العدادات، الذاكرة |
| `L` | الإشارة الحية كل 150 ms، فقط في صفحتي الراديو والفني |
| `D` | أسماء المفككات |

**من الشاشة إلى الراديو:**
- `{"c":"cfg","bw":102}`، وكذلك `foff` و`d` و`mask`.
- `{"c":"live","on":1}`.
- `{"c":"dec"}`.
- `{"c":"reboot"}`.

## الواجهة (5 صفحات)
1. **CAR**: السيارة و4 بطاقات و الاحتياطي. اللون أخضر أو برتقالي أو أحمر، والوميض عند الخطر. لمس الشريط العلوي يُسكت الإنذار.
2. **SCAN**: كل الحساسات المسموعة. لمس أي صف يفتح نافذة لربطه بإطار (FL/FR/RL/RR/SP).
3. **RADIO**: عدّاد الإشارة الحية ومنحنى آخر 18 ثانية. تعديل عرض النطاق وإزاحة التردد والحساسية من الشاشة.
4. **TECH**: وضع فني الإطارات. يلتقط أقرب حساس فقط (فوق عتبة dBm قابلة للتعديل) ويعطي حكماً: سليم، بطارية ضعيفة، 0 بار.
5. **SETUP**:
   - السطوع (يدوي أو تلقائي بحساس الضوء)، والوحدات bar/psi/kPa، والصوت، وانعكاس الألوان وترتيب RGB، ومعايرة اللمس.
   - المعرّفات الأصلية مع زر الاستعادة.
   - الحدود لكل إطار.
   - النظام: الواي فاي وإعادة التشغيل.

> **ألوان الشاشة غلط؟** من SETUP ← DISPLAY غيّر `COLOR INVERT` أو `RGB ORDER`. لوحات CYD بشريحة ST7789 تختلف بين الدفعات.

## الواي فاي
- الشبكة `TPMS-V3` وكلمة المرور `12345678`. الصفحة تفتح تلقائياً، أو افتح `http://192.168.4.1`.
- صفحة عربية فيها:
  - الإطارات.
  - الماسح مع الربط.
  - الراديو مع التعديل.
  - الإعدادات.
- يمكن إيقاف الواي فاي من الشاشة.

## أوامر التشخيص (USB)
- **وحدة الشاشة:**
  - `stat`، `tires`، `reboot`.
  - `tap X Y` لمحاكاة لمس.
  - `page N` لفتح صفحة.
  - `shot` لتصوير الشاشة بصيغة base64 RGB565، تحوّلها `tools/shot2png.py` إلى صورة.
- **وحدة الراديو:** `stat`، `bw N`، `foff N`، `rssi`، `log on/off`، `reboot`.
